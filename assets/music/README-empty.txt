Положи сюда свою фоновую музыку (mp3, wav, m4a или ogg).

Используй только треки с лицензией, которая разрешает коммерческое использование:
- Pixabay Music (https://pixabay.com/music/) — бесплатно, без указания автора для Shorts;
- свои треки или треки с явной лицензией.

В ролике включается в deck.music: {"enabled": true, "file": "имя.mp3", "volume": 0.12}.
Если file не указан, берётся первый файл из этой папки.
